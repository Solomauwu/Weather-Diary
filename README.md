# 🌤️ Weather Diary — Погодный дневник

**Автор:** Кира Иванова

## 📝 Описание программы

Консольное приложение для ведения дневника погоды. Позволяет записывать ежедневные наблюдения за погодой, просматривать историю, фильтровать записи, строить графики температуры и сохранять данные в JSON-файл.

## ✨ Возможности

- ➕ Добавление записей о погоде (дата, температура, описание, осадки)
- 📋 Просмотр всех записей с иконками погоды
- 🗑️ Удаление записей по дате
- 🔍 Фильтрация по диапазону дат
- 🌡️ Фильтрация по диапазону температур
- 📊 Построение графика температуры (с помощью matplotlib)
- 📈 Статистика (средняя, максимальная, минимальная температура, сумма осадков)
- 💾 Автоматическое и ручное сохранение в JSON
- 📂 Загрузка данных из JSON-файла
- 🤖 Автоматическое определение типа погоды (Солнечно ☀️, Дождливо 🌧️, Снежно ❄️, Облачно ☁️)
- ✅ Полная проверка корректности ввода

## 🚀 Как запустить приложение

### Требования
- Python 3.8 или выше
- Установленный pip

### Установка и запуск

```bash
# 1. Скачайте или склонируйте репозиторий
git clone https://github.com/kiraivanova/WeatherDiary.git
cd WeatherDiary

# 2. Установите необходимые библиотеки
pip install matplotlib

# 3. Запустите приложение
python main.py
